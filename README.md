## Overview

Odin 2 is a powerful free synthesizer combining wavetable, PM, and analog VA oscillator types with a 6×8 modulation matrix, three effects slots, and a built-in arpeggiator and step sequencer.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Odin 2** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Three Oscillator Types** | Wavetable, FM/PM, and analog VA oscillators in any combination |
| **6x8 Mod Matrix** | 48-slot modulation matrix with speed-controlled routing |
| **Three FX Slots** | Reverb, delay, chorus, phaser, and flanger on-board effects |
| **Step Sequencer** | 64-step sequencer with pitch, velocity, and modulation lanes |
